# PDF白マスク消去・解答完全復元Webアプリ

講義スライド等のPDFから、**白マスク（空欄・目隠し図形）そのものを完全消去**し、隠れていた文字や図表を100%元のレイアウト・フォント・配置のまま復元するWebアプリです。

## 特徴
- **大きい幅の隠し・複数行にも完全対応**: 上からテキストを再描画するのではなく、白マスク図形そのものを消去するため、どんな大きな隠しでも元の姿に戻ります。
- **フォントずれ・文字被りゼロ**: 元のPDFが保持しているフォント、文字サイズ、文字詰め、下線、文字色（黒・赤など）がそのまま現れます。
- **スマホ・タブレット・PC対応**: ブラウザからPDFをドラッグ＆ドロップするだけで一括処理・ダウンロード可能です。
